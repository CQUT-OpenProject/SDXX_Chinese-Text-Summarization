# 中文摘要实验数据

基于仓库提交 `b06ea5e`（改写前为 `39cf99b`），2026-10-31 在本机 NVIDIA GeForce RTX 4070 SUPER 上运行；模型使用 GPU，截取和 TextRank 使用 CPU。训练及评价的软件版本和数据、代码哈希见 manifest.json。

数据集采用固定版本的 LCSTS 整理版，验证集和自划分测试集分别包含 1,000 条与 725 条有标签验证样本。2K 训练集是 10K 的子集，各数据划分的原文精确交集均为零；近似重复可在后续实验中进一步检查。每组使用种子 42 训练一次。

ROUGE 为字符级逐样本 F1 均值，范围 0–1；耗时统计 725 条样本的逐条生成过程，模型加载和 ROUGE 计算另计，结果受设备及负载影响。

## 文件说明

- `results.csv` 与 `metrics.json`：六种方法的完整指标、输出长度、耗时；TextRank 的具体参数也在 JSON 中。
- `bart-*-trainer_state.json`：每 50 步训练损失、各轮验证损失和训练耗时，可用于绘制损失曲线；`bart-*-config.json` 保存训练配置。
- `cases.jsonl`：按测试集顺序保存全部 725 条完整原文、参考摘要和六种方法的输出，索引从 0 开始，可用于选择案例并人工核对事实。
- `manifest.json` 和 `split_info.json`：数据来源、划分、输入文件哈希及运行环境。

ROUGE 衡量文本重合度；事实一致性可结合案例和人工标注分析。每组结果来自一次固定种子实验，多次重复实验可进一步检验指标差异的稳定性。
